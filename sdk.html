npm

How it works

402 → pay → retry, automatically

The SDK intercepts every 402 response and handles the full payment cycle without any code from you.

1

Request sent

The SDK sends your request (with a cached receipt header if one exists). The server checks for a valid receipt.

2

402 received

If no valid receipt, the server returns 402 Payment Required with USDC amount, recipient, and network details.

3

Authorizations signed

The SDK signs EIP-3009 transferWithAuthorization for publisher (95%) and commission (5%) — locally, no on-chain TX from the agent.

4

Retry with X-PAYMENT

The SDK retries the request with a base64-encoded X-PAYMENT header containing both signed authorizations.

5

Receipt cached

The middleware verifies signatures, submits transactions via its facilitator wallet, and issues a signed receipt in X-PAYMENT-RESPONSE. Cached per scope until expiry.

Quick start

Two minutes to first request

You need a private key for a wallet with USDC on Base, and the URL of the publisher's server.

agent.js
const { AgentClient } = require('agent-toll-sdk');

const client = new AgentClient({
  wallet: process.env.AGENT_PRIVATE_KEY,   // 0x... private key
  baseUrl: process.env.BASE_URL,              // publisher's server URL
});

// First call: pays automatically if needed, then returns content
const article = await client.get('/article/123');

// Second call: reuses the cached receipt — no payment
const same = await client.get('/article/123');
One client per publisher. Receipts are scoped to a specific publisher's routes. Create separate AgentClient instances for different publisher origins.
Configuration

Constructor options

Pass these to new AgentClient(options).

Option Default Description
wallet required Private key string (0x...) or an ethers.js Wallet / Signer instance. This wallet pays for content — keep it funded with USDC on Base.
baseUrl required The publisher's server URL, e.g. https://publisher.example.com. All relative paths are resolved against this.
trustedSignerAddress from 402 body The receipt signer address you trust for this publisher. Recommended in production — prevents a compromised publisher from injecting a fake signer. If omitted, the SDK learns it from the first 402 response.
maxRetries 3 Maximum number of attempts per request before throwing. Retries use exponential backoff.
retryBaseDelayMs 100 Base delay in ms for exponential backoff. Delay on attempt N is retryBaseDelayMs × 2^(N-1).
logging true Set to false to silence SDK console output.
fetchImpl globalThis.fetch Custom fetch implementation. Useful for environments without native fetch or for testing with a mock.
API

Methods

All methods return the parsed response body (JSON object or string). They throw on non-2xx responses after the payment flow completes.

client.get(path, options?)

Sends a GET request. Handles 402 automatically. Returns the response body.

client.post(path, body, options?)

Sends a POST request with body serialized as JSON. Handles 402 automatically.

client.put(path, body, options?)

Sends a PUT request with body serialized as JSON.

client.patch(path, body, options?)

Sends a PATCH request with body serialized as JSON.

client.request(method, path, options?)

Low-level method. Use when you need a custom HTTP method. Options can include headers and body.

Options object

KeyDescription
headers Extra request headers merged with the SDK's default headers (X-Agent-Type, X-Agent-Wallet, X-PAYMENT).
body Request body for POST/PUT/PATCH. Automatically JSON-serialized.

Receipt cache

The client exposes its receipt cache as client.receiptCache — a Map keyed by scope (path). Useful for debugging or pre-warming.

example
// Check if a receipt is cached for a path
const cached = client.receiptCache.has('/article/123');

// Clear the cache (force re-payment on next request)
client.receiptCache.clear();
Advanced

Multiple publishers

Create one client per publisher. Receipts and payment state are scoped to each client instance.

multi-publisher.js
const { AgentClient } = require('agent-toll-sdk');

const siteA = new AgentClient({
  wallet: process.env.AGENT_PRIVATE_KEY,
  baseUrl: 'https://news.example.com'
});

const siteB = new AgentClient({
  wallet: process.env.AGENT_PRIVATE_KEY,
  baseUrl: 'https://docs.example.com'
});

const [article, doc] = await Promise.all([
  siteA.get('/article/123'),
  siteB.get('/api/guide')
]);
Environment variables

Env vars for agents

The SDK reads from options only — no env vars are read automatically. These are the conventions used in examples and the example integration script.

Variable Used for
AGENT_PRIVATE_KEY Pass to wallet. A hex private key (0x...) for a wallet holding USDC on Base.
BASE_URL Pass to baseUrl. The publisher's middleware server URL.
RECEIPT_SIGNER_ADDRESS Pass to trustedSignerAddress. Recommended for production — pins you to a specific publisher signer.
.env
AGENT_PRIVATE_KEY=0x...
BASE_URL=https://publisher.example.com
RECEIPT_SIGNER_ADDRESS=0x...          # optional, recommended in prod
Error handling

Errors and edge cases

The SDK throws standard JS errors. Errors from failed HTTP requests include status and body properties.

error-handling.js
try {
  const data = await client.get('/article/123');
} catch (err) {
  if (err.status === 402 && err.body?.error === 'beta_limit_exceeded') {
    // Publisher has hit a spend or rate limit
    console.warn('Spend limit reached, try again later');
  } else if (err.status) {
    // Any other HTTP error
    console.error(`HTTP ${err.status}`, err.body);
  } else {
    // Network error, RPC failure, etc.
    console.error(err.message);
  }
}

Common errors

ErrorCause
402 beta_limit_exceeded Publisher's spend or request cap was hit. Non-retriable — don't retry immediately.
Unsupported chain The RPC URL pointed at a non-Base chain. Only Base mainnet and Base Sepolia are supported.
wallet is required No wallet was passed to the constructor.
