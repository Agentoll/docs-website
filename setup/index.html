What is Agent-Toll?

Bot detection plus x402 USDC micropayments on Base. Humans pass through free; automated clients pay a micro toll (~0.000002 USDC) to continue.

Agentoll is hosted script-tag SaaS. You register once, paste one script tag in your site’s <head>, and go live. No npm install, DNS changes, or operator secrets on your side.

How traffic is handled

flowchart LR
  Human[Human browser] -->|script detects human| Pass[Free access]
  Bot[Bot / agent / curl] -->|payment required| Pay[USDC on Base]
  Pay --> Session[Session token]
  Session --> Pass
  • Humans — real browsers are detected and pass through with no payment or friction.
  • Bots, curl, and agents — classified as automated; they pay a micro USDC toll on Base via x402, then receive a short-lived session token.
  • No install for basic use — one script tag is enough for in-browser protection.
  • Optional Node middleware — add the agentoll package if you need HTTP 402 blocking for curl and server-side routes.

Two setup paths

Default

Script only

Any website with a <head>. Register → embed → done. In-browser wall only.

 Optional

Script + server gate

Node / Express / Next with a server. Same script plus npm install agentoll middleware. Blocks curl at HTTP 402.
PathWhoBlocks curl at HTTP layer?

What you never configure

Publishers do not set payment facilitator URLs, RPC endpoints, CDP keys, DNS proxy records, alternate origin URLs, or platform wallet addresses. Registration gives you a publisher ID and embed snippet; the platform runs settlement.
