FAQ

Answers for publishers setting up Agentoll for the first time.

Do humans pay?

No. Real browsers pass through free with no payment wall.

How much do bots pay?

About 0.000002 USDC per access on Base (configurable by the platform).

Do I need a wallet to set up?

You register your wallet for revenue attribution. Visitors’ agents pay from their own wallets when they hit the toll.

Do I need npm?

Only if you want HTTP 402 on server routes — install the agentoll package. Script-only needs no npm.

Do I need DNS changes?

No. Paste the script tag on your existing site — no DNS records to add or change.

What is the API key for?

Server gate middleware (X-Publisher-Key / apiKey option) and optional stats API (/v1/publishers/me/stats). Not required in HTML for script-only.

Script only vs server gate?

Script only = in-browser detection and payment wall. Server gate = same script plus Node middleware that also blocks curl and agents at HTTP 402.

What happened to the agent-toll npm package?

v3 removed self-hosted middleware for publishers. Use the hosted script tag plus optional agentoll for server gate.

Where does USDC go?

On-chain to the platform operator wallet. Your registered wallet is used for revenue share and attribution.

Is this x402?

Yes. v2 headers: payment-required, payment-signature, payment-response.
