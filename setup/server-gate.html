Quickstart — Server gate

Optional — for sites with a Node server. Add the agentoll middleware to return HTTP 402 for curl and unpaid agents, in addition to the browser embed script.

Steps

StepAction
1 Register at agentoll.net/register — choose Script + server gate and save your API key (atk_..., shown once)
2 Add the same embed script to <head> (browser wallet UX for humans and paying agents)
3 npm install agentoll
4 Mount middleware before protected routes

Express example

const express = require('express');
const { createGate } = require('agentoll');

const app = express();

app.use(
  createGate({
    apiKey: process.env.AGENTOLL_API_KEY,
    publicOrigin: 'https://www.example.com'
  }).express()
);

app.get('/article', (req, res) => {
  res.send('<html>...</html>');
});

app.listen(3000);

publicOrigin is optional — set it to your registered public URL if it differs from the request host.

Embed script (same as script-only)

<script
  src="https://agentoll-middleware-p5aon.ondigitalocean.app/v1/agent-toll.js"
  data-publisher-id="pub_xxxxxxxx"
  async
></script>

Verify with curl

curl -sI "https://www.example.com/article" -H "User-Agent: curl/8"

Expect: HTTP 402 with a payment-required header.

Behavior

ClientResult
Human browserPage served normally
curl / bot (unpaid)402 + payment-required header
Paid retry with payment-signature200 + session cookie

No DNS changes required. The server gate talks to the hosted API with your API key — no self-hosted middleware.

Package docs See agentoll on npm and SERVER_GATE.md for options.
